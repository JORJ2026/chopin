# Privacy

Multicart does not collect, send or sell any data. There are no accounts, analytics, ads or cookies.

- MIDI files you import are read in your browser or app and never uploaded.
- Settings, favourites and play history are stored on your device (browser local storage) and can be cleared in Settings, Library, or reset in Settings, General.
- The web version loads from GitHub Pages, so GitHub sees ordinary web-server requests for the page. Downloads come from GitHub Releases.
- The app makes no other network requests.
