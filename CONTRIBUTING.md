# Contributing

Issues and pull requests are welcome.

- The app is a single file, `index.html`. Keep it dependency-free.
- Run `npm run serve` and test in a browser. Test both layouts of the roll and both themes.
- Do not add MIDI files without a clear licence. Record the source in `NOTICE.md`.
- Bump `VERSION` in `sw.js` when you change anything the app serves.
